# Próximos passos de implementação

1. Inicializar app Next.js (`npx create-next-app@latest`).
2. Instalar Prisma (`npm i prisma @prisma/client`).
3. Rodar migração inicial (`npx prisma migrate dev --name init`).
4. Criar rotas CRUD:
   - `/foods`
   - `/meals`
   - `/workouts`
   - `/measurements`
5. Implementar dashboard com gráficos de evolução mensal.
